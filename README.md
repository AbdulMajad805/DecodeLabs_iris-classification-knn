# Iris Flower Classification using K-Nearest Neighbors (KNN) 🌸

I developed this project as part of my Artificial Intelligence Internship at DecodeLabs.

The objective of this project is to build a basic machine learning classification model using the famous Iris dataset and the K-Nearest Neighbors (KNN) algorithm.

---

## 🚀 Features

- Dataset loading and exploration
- Data preprocessing and feature scaling
- Train-test data splitting
- KNN model training
- Prediction on test data
- Accuracy evaluation
- Confusion matrix visualization
- Classification report generation
